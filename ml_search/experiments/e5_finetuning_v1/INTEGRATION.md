# Экспериментальное подключение

Исходная конфигурация остаётся режимом по умолчанию. Обычный запуск:

```powershell
& powershell.exe -NoProfile -ExecutionPolicy Bypass -File ".\ml_search\run.ps1" -Model small
```

Выбранная дообученная модель, согласованный с ней отдельный индекс и
консервативный распознаватель названий включаются одной командой:

```powershell
& powershell.exe -NoProfile -ExecutionPolicy Bypass -File ".\ml_search\run_experimental.ps1"
```

Скрипт перед запуском проверяет наличие всех трёх экспериментальных артефактов.
API `/health` показывает фактическое имя модели и состояние распознавателя
названий. Для отката нужно остановить экспериментальный процесс и выполнить
обычный запуск: экспериментальные переменные существуют только внутри процесса
скрипта и не меняют системное окружение.

Рабочие веса ранжирования и тексты книг не меняются. Новые векторы запросов
всегда используются только вместе с экспериментальным индексом книг.
