# Итоговая проверка выбранного поиска

## Что проверено

Выбранная конфигурация была зафиксирована до запуска:

- дообученная модель `multilingual-e5-small-finetuned-lr1e-5-epoch3`;
- соответствующий основной индекс всех 1000 книг;
- отдельные векторы сюжета, аннотации, характерных деталей и атмосферы;
- доля многовекторной оценки 0,60;
- прежние веса первого этапа и обработчик названий.

Закрытый тест содержит 99 синтетических запросов из 33 семейств. Разметка была
зафиксирована до первой выдачи выбранного поиска. В 23 семействах есть хорошо
подходящие книги, в пяти — только частично подходящие, ещё пять семейств не
имеют подтверждённого ответа в каталожных профилях.

Разметка редакционная: запросы и оценки созданы одним AI-агентом по поисковым
описаниям каталога. Это защищает от подбора настроек по результатам теста, но не
заменяет независимую человеческую оценку и реальные запросы покупателей.

## Общий результат

| Показатель | Рабочая модель | Выбранный вариант | Разница |
|---|---:|---:|---:|
| NDCG@10 | 0,0785 | **0,2279** | **+0,1494** |
| Hit@3 | 4,35% | **10,14%** | **+5,80 п.п.** |
| Hit@10 | 14,49% | **31,88%** | **+17,39 п.п.** |
| p95 | 2211 мс | 2271 мс | +2,74% |

Предварительно согласованный критерий NDCG@10 +0,03 выполнен с большим
запасом. Увеличение p95 существенно ниже допустимых 20%.

Абсолютное качество всё ещё невысокое: хорошо подходящая книга находится в
первых десяти результатах примерно для 32% запросов с хорошим ответом. Поэтому
результат подтверждает заметное улучшение, но не завершение работы над поиском.

## Результаты по группам

| Группа | NDCG@10 до | NDCG@10 после | Hit@3 после | Hit@10 после | p95 после |
|---|---:|---:|---:|---:|---:|
| Атмосфера | 0,0439 | **0,3227** | 16,67% | 33,33% | 2104 мс |
| Разговорные запросы | 0,1350 | **0,3592** | 22,22% | 55,56% | 2228 мс |
| Настроение | 0,0417 | **0,1082** | 0% | 16,67% | 2251 мс |
| Отрицания | 0,0962 | **0,1225** | 4,76% | 28,57% | 2104 мс |
| Пересказ сюжета | 0,0672 | **0,2611** | 22,22% | 44,44% | 2416 мс |
| Специализированные запросы без ответа | не применяется | не применяется | не применяется | не применяется | 2210 мс |

У отрицаний Hit@3 снизился с 9,52% до 4,76%, хотя NDCG и Hit@10 выросли. Это
главная качественная регрессия закрытого теста. Повторно менять текущую
конфигурацию по этому результату нельзя: тест уже открыт. Отрицания нужно
исправлять в следующем эксперименте на новой настроечной выборке.

## Книги вне обучения

Для 75 запросов все размеченные подходящие книги отсутствовали среди
положительных, отрицательных и дополнительных положительных книг обучающей
выборки.

| Показатель | Рабочая модель | Выбранный вариант |
|---|---:|---:|
| NDCG@10 | 0,0780 | **0,2252** |
| Hit@3 | 3,33% | **8,33%** |
| Hit@10 | 13,33% | **28,33%** |

Улучшение сохраняется на книгах вне обучения, поэтому результат не объясняется
только запоминанием конкретных обучающих книг.

## Примеры

Новая конфигурация подняла подходящую книгу:

- по атмосфере чужой цивилизации — с 5-го на 1-е место;
- по присвоению чужой личности — с 8-го на 1-е;
- по ночному городу — с отсутствия в топ-10 на 2-е и 4-е места;
- по долгам и бытовым последствиям — с отсутствия в топ-10 на 1-е место;
- по возвращению домой и семейной тайне — с отсутствия в топ-10 на 1-е место.

Зафиксированы ухудшения:

- романтика без любовного треугольника: 5-е место → за пределы топ-10;
- триллер без мистики: 2-е → 8-е;
- юмористическая научная фантастика без магии: 3-е → 5-е;
- группа после аварии: 10-е → за пределы топ-10;
- отношения матери и дочери: 1-е → 7-е.

## Запросы без ответа

Ни рабочая, ни новая конфигурация не объявила пустой результат для 15 запросов
из пяти семейств без подтверждённой книги. Обе вернули ближайшие книги.

Это соответствует принятому безопасному поведению: низкая уверенность модели
не доказывает отсутствие книги, поэтому `no_matches` используется только когда
строгие фильтры объективно оставили ноль кандидатов. Однако автоматическое
различение «слабое совпадение» и «ответа в каталоге нет» остаётся нерешённым.

## Обязательные проверки

Прошли все проверки:

- название книги;
- автор;
- опечатка в названии;
- строгие фильтры;
- пустой ввод;
- разбор запроса в «Алхимии»;
- результаты «Алхимии»;
- обычные рекомендации.

Также ранее прошли 98 автоматических тестов проекта.

## Решение

Эксперимент успешен: новая модель вместе с многовекторным индексом заметно
лучше действующей модели, переносит улучшение на книги вне обучения и укладывается
в ограничение скорости.

Конфигурацию следует считать кандидатом для опытного подключения или A/B-теста.
Полное включение для всех пользователей пока преждевременно из-за низкого
абсолютного Hit@3, слабой обработки отрицаний, отсутствия надёжной пустой выдачи
и отсутствия независимой человеческой разметки.
