# Обучающая выборка: первый эксперимент

Основной файл — `train.jsonl`: 512 уникальных естественных запросов по 64 книгам, по восемь формулировок на книгу. У 34 записей есть сложный отрицательный пример. `train_triplets.jsonl` — подмножество основного файла, а не дополнительные примеры. `train_pairs.jsonl` сохраняет исходные положительные пары до проверки отрицательных кандидатов.

Запросы написаны синтетически и проверены агентом по текущим поисковым профилям каталога. Независимая проверка человеком не проводилась. Полные романы не использовались. Положительные и отрицательные тексты совпадают с `Book.search_text`, который получает действующий поиск. Записи содержат идентификаторы каталога и магазина, основания разметки, цитаты из профилей и контрольные суммы.

Для 128 запросов исходная модель использована для поиска сложных кандидатов. В 51 случае нашлись разрешённые книги выше целевой книги. Редакционно проверены 42 кандидата: 34 приняты как отрицательные, восемь отклонены как подходящие, частично подходящие или неоднозначные. Два подходящих кандидата добавлены как дополнительные положительные ответы. Все остальные кандидаты остаются непроверенными и не должны использоваться как отрицательные.

Отрицательная оценка относится только к конкретному запросу и его обязательным условиям. Отсутствие книги в положительной разметке не означает, что она не подходит. Разметка не перечисляет все возможные ответы каталога.

Проверочные 77 запросов, их диагностические переформулировки, dev и закрытый тест не включены в обучение. Родственные запросы объединены по книгам. Для всех обучающих ролей исключена 141 книга, включая дополнительную редакцию «Белых ночей» (887), обнаруженную при расширении исключений dev. Исходная замороженная политика и файлы оценки не менялись; дополнительное исключение хранится в `batch-policy.json`. Сопоставление текстов не нашло точных совпадений с отложенными запросами; само по себе оно не доказывает отсутствие всех смысловых пересечений.

При дальнейшем обучении соблюдать `batch-policy.json`: варианты одной книги, серии и совместимые книги нельзя без проверки превращать во взаимные отрицательные примеры внутри пакета. Учитывать дополнительные положительные ответы. Префиксы E5 `query: ` и `passage: ` добавлять один раз при подготовке входа модели; сохранённые профили уже содержат исходный текст поиска, без этих префиксов.

`candidate-review-log.json` содержит решения по кандидатам; `REVIEWED_EXAMPLES.md` позволяет прочитать все 34 тройки. `training-manifest.json` фиксирует контрольные суммы данных. `validation-results.json` содержит проверку идентификаторов, точных текстов, исключений, состава троек, неизменности отложенной оценки и восьми исходных файлов поиска.

Дообучение не запускалось. Модель, индекс и действующий поиск не изменены. Объём 512 примеров — стартовый эксперимент, а не гарантия улучшения. Ошибки разбора запроса и метаданных, найденные на этапе аудита, требуют отдельного исправления.
